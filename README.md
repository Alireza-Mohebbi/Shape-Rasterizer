# Shape Rasterizer
Using this console program, you can define arbitrary lines and polygons and get the pixel coordinates of the rasterized shape.

# Underlying Algorithms
1. Line rasterization: Bresenham's line rasterization algorithm.
2. Polygon rasterization: Pineda's polygon rasterization algorithm.

# How To Run The Program
Prerequisite:
1. Visual Studio installed.
2. .Net framework v4.8.1 or newer.

To run the program, follow these steps:
1. Download the repository.
2. Open the file with .sln format; You will enter the Visual Studio.
3. In Visual Studio, start (run) the program.
